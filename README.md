# Boca Libre releases

This public repository hosts the signed update feed and downloadable releases for Boca Libre, a private press-to-dictate Mac app.

- Download installers from [Releases](https://github.com/rsrinivasan02/boca-libre-releases/releases).
- Every app update is notarized by Apple and signed separately for Sparkle verification.
- This repository contains release artifacts only. Boca Libre's source repository remains private.
